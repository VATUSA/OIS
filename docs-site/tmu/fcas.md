# Flow Constrained Areas

A **Flow Constrained Area** (FCA) is a shape you draw on the map to identify and meter the traffic crossing it — the building block for most flow initiatives in OIS.

## Building an FCA

1. Open the FCA map and start a new area.
2. Draw the polygon on the map (click to add points, double-click or Enter to finish).
3. Name it and set its **filters** — which traffic counts:
   - **Altitude** band
   - **Direction** of crossing
   - **Destination** (e.g. only arrivals to a field)
   - **Scope** — limit to specific ARTCCs' airspace.

## Metering crossings

Once an FCA exists, OIS finds every aircraft whose **filed route** crosses it, computes each one's ETA to the crossing, and sequences them. You can apply spacing — **miles-in-trail** or **minutes-in-trail** — and the map shows the matched aircraft tinted and numbered in order.
