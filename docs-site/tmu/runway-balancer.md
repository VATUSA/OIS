# Runway Balancer

The **Runway Balancer** helps you spread an airport's arrivals across its runways and see where demand is bunching.

## What it shows

- A shared **arrival → runway assignment** for the field.
- A **10-minute demand board** — arrivals bucketed into 10-minute windows so you can spot a wave before it hits.

Because the assignment is shared, every controller working the field sees the same runway picture and the same demand.
