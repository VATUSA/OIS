# The home page

The page you land on at OIS's root — what it shows depends on whether you're signed in.

## Signed out

A short pitch plus a feature grid (traffic management, FCAs, event planning, runway balancer,
facility maps, historical replay), and three ways to explore without an account: the public
[advisories board](/advisories/board), a read-only FCA overview, and [facility maps](/map/facility-map).
**Sign in with VATSIM** starts the sign-in flow described in [Signing in](/introduction/signing-in).

## Signed in

![Signed-in home page: live counts for pilots online, metering programs, ground stops, and restrictions, each with a list section below.](/screenshots/dashboard-home.png)

A launchpad, not a report: a row of live counts (upcoming/ongoing events, active metering
programs, active ground stops, active restrictions) plus a list section per category, each with a
**View all** link into the matching TMU or planning tool. If an event is happening right now, or
one is coming up, it's called out at the top with a countdown. Everything here updates live —
counts and lists reflect the current board state, not a cached snapshot.

The home page is a jumping-off point, not a workspace. For a page you actually configure yourself
— pin the specific stats and views you check every session — see [Custom boards](/dashboard/boards).
