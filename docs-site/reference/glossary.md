# Glossary

| Term | Meaning |
| ---- | ------- |
| **AADC** | Airport Arrival Demand Chart — bucketed forward arrival demand for an airport against its AAR. See [Arrival demand chart](/tmu/aadc). |
| **AAR** | Airport Acceptance Rate — arrivals per hour a field will accept. |
| **ADR** | Airport Departure Rate — departures per hour a field will accept. |
| **API key** | A personal access token (`ois_pat_…`) for calling the OIS API as yourself, capped by your live permissions. See [API keys](/reference/api-keys). |
| **ARTCC** | Air Route Traffic Control Center (e.g. ZDC). |
| **Bearer token** | A credential sent as `Authorization: Bearer …` — either a user API key or a service account. |
| **CFR** | Controlled Flight Rules release — an issued wheels-up time for a departure. |
| **CTA** | Controlled Time of Arrival — the arrival slot a flight is metered into. |
| **EDCT** | Expect Departure Clearance Time — a flight's controlled wheels-up time, produced by a GDP or a CFR release. |
| **FCA** | Flow Constrained Area — a line drawn across a flow to meter the traffic crossing it. |
| **GDP** | Ground Delay Program — meters arrivals to an airport by holding departures on the ground. |
| **IDST** | Integrated Departure Scheduling — the console for working FCA-metered ground departures and issuing CFR releases. |
| **MIT / MINIT** | Miles-in-trail / minutes-in-trail spacing. |
| **RDY** | Ready — releasing a departure into the earliest open slot (as opposed to pinning it to a set time). |
| **STA** | Scheduled Time of Arrival — a flight's metered arrival time. |
| **STAR** | Standard Terminal Arrival Route — the filed arrival procedure; OIS reads it from the route as a flight's arrival gate. |
| **TMU** | Traffic Management Unit — the desk that runs flow initiatives. |
| **TRACON** | Terminal Radar Approach Control — the approach/departure airspace around busy airports. |
