# Glossary

| Term | Meaning |
| ---- | ------- |
| **AAR** | Airport Acceptance Rate — arrivals per hour a field will accept. |
| **ARTCC** | Air Route Traffic Control Center (e.g. ZDC). |
| **CFR** | Controlled Flight Rules release — an issued wheels-up time for a departure. |
| **CTA** | Controlled Time of Arrival — the arrival slot a flight is metered into. |
| **EDCT** | Expect Departure Clearance Time — a flight's controlled wheels-up time under a GDP. |
| **FCA** | Flow Constrained Area — a drawn area used to meter crossing traffic. |
| **GDP** | Ground Delay Program — meters arrivals to an airport by holding departures on the ground. |
| **MIT / MinIT** | Miles-in-trail / minutes-in-trail spacing. |
| **STA** | Scheduled Time of Arrival — a flight's metered arrival time. |
| **TMU** | Traffic Management Unit — the desk that runs flow initiatives. |
| **TRACON** | Terminal Radar Approach Control — the approach/departure airspace around busy airports. |
