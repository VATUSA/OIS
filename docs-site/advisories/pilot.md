# Flight lookup

The **flight lookup** (the *My flight* page) lets a pilot check how active traffic management affects a specific flight — no sign-in needed.

## Using it

1. Open the pilot page.
2. Type your **callsign** (fuzzy search helps — see [Finding a flight](/map/flight-search)).
3. See any initiatives affecting the flight: an assigned EDCT, a delay, or a ground stop, plus a link to show the flight on the FCA map.

If nothing is affecting your flight, the page says so.
